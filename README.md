# 칼바람 나락(아수라장) 아이템·증강 추천

게임에서 아군과 상대의 챔피언·아이템을 읽어서, 내 역할(탱커/딜러/브루저/인챈터)에 맞는 다음 아이템과 증강을 추천합니다.
직접 입력하는 것은 없습니다. Python 3 표준 라이브러리만 사용합니다.

## 실행 (Windows)

zip으로 받거나 clone한 폴더에서 `run.bat`을 더블클릭하고 메뉴 번호를 고릅니다.

- Python이 없으면 자동으로 설치합니다. winget이 있으면 winget으로, 없으면 python.org 설치 파일로 설치하며,
  사용자 계정에만 설치하므로 관리자 권한이 필요 없습니다. 첫 실행은 인터넷 연결이 필요합니다.
- 인터넷에서 받은 bat 파일이라 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행"을 누르세요.
- `run.bat live --watch 2 --role tank`처럼 인자를 붙이면 그대로 전달합니다.
- `run.bat`은 CP949(EUC-KR)로 저장되어 있습니다. UTF-8로 저장하면 메뉴 한글이 깨지니 편집할 때 인코딩을 유지하세요.
- 메뉴 1번은 자동 분석 + 웹페이지(http://localhost:8765) + 증강 선택 화면 읽기, 2번은 여기에 음성 안내를 더합니다.
- 메뉴 8번은 Windows 로그인 시 1번을 최소화된 창으로 자동 실행되게 등록합니다. 이미 실행 중인 창이 있으면 웹페이지 포트가 겹쳐 새 창은 웹페이지 없이 동작합니다. 게임이 없을 때는 기다리다가
  게임이 시작되면 분석하고, 게임이 끝나면 다음 게임을 기다립니다.

### 다른 PC에서 사용할 때

| 조건 | 내용 |
|---|---|
| zip은 압축을 풀고 실행 | zip 안에서 run.bat을 바로 열면 다른 파일을 못 찾아 실패합니다. "압축 풀기" 후 실행하세요. |
| 한국어 Windows | run.bat은 CP949로 저장되어 있어 영어 Windows에서는 메뉴 글자가 깨질 수 있습니다. 화면 OCR에는 한국어 언어팩이 필요합니다(한국어 Windows는 기본 포함). |
| Python | 3.8 이상을 찾아 쓰고, 없거나 3.8 미만이면 자동으로 설치합니다. |
| 첫 실행 경고 | "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행"을 누르세요. |
| 웹페이지 방화벽 | 처음 `--serve`로 실행할 때 허용 여부를 물으면 허용하세요(휴대폰으로 보려면 필요). |
| 인터넷 | 첫 실행 때 Data Dragon·OP.GG·CommunityDragon 데이터를 받아 `data/`에 저장합니다. |
| 화면 읽기 | 롤을 테두리 없는 창 모드로, 주 모니터에서 실행하세요. |

## 명령

```bash
# 증강 선택 화면의 선택지 비교와 리롤 판단 (게임 중, 이미 리롤한 칸은 이름 끝에 *)
python3 -m aram_helper pick 둠 핀볼 "남작의 도움"
python3 -m aram_helper pick 둠 "핀볼*" "남작의 도움*"

# 게임 기록과 추천을 따랐을 때의 승률
python3 -m aram_helper history

# 게임 중 자동 분석 (2초마다 확인, 내 챔피언이 죽는 순간과 게임 시작 직후에만 추천)
python3 -m aram_helper live --watch 2

# 저장된 게임 데이터로 미리 보기 (테스트용)
python3 -m aram_helper live --file samples/sample_allgamedata.json

# 아이템 골드 효율표
python3 -m aram_helper efficiency
```

### 전체 화면 게임 중에 추천 받기
전체 화면 게임 위에 창을 직접 그리려면 게임 그래픽에 코드를 끼워 넣어야 하는데, 안티치트(Vanguard) 제재 위험이 있어
쓰지 않습니다. 대신 화면과 상관없이 동작하는 두 가지 방법을 씁니다.

```bash
# 음성 안내 + 웹페이지
python3 -m aram_helper live --watch 2 --speak --serve 8765
```

- `--speak`: 죽는 순간 "아이템 모렐로노미콘, 폭풍 쇄도. 증강 기본으로 돌아가기, 남작의 도움." 형식으로 읽어줍니다.
  Windows 음성 합성을 쓰며, 한국어 음성(Microsoft Heami 등)이 있으면 자동으로 고릅니다. WSL에서도 동작합니다.
- `--serve 8765`: 추천 결과를 웹페이지로 띄웁니다. 3초마다 자동으로 새로고침되며, 사망 여부와 부활까지 남은 시간도 표시합니다.
  - 같은 PC나 보조 모니터에서는 `http://localhost:8765`로 봅니다.
  - `http://localhost:8765/augments`에서 증강 선택지 3개를 입력하면 지금 게임 상황 기준으로 순위를 보여줍니다.
  - **휴대폰으로 보려면 Windows용 Python으로 실행해야 합니다.** WSL의 IP(172.x)는 휴대폰에서 접속할 수 없습니다.
    시작할 때 출력되는 `http://192.168.x.x:8765` 주소를 같은 와이파이의 휴대폰에서 열면 됩니다.
    처음 실행할 때 Windows 방화벽이 허용 여부를 물으면 "개인 네트워크"를 허용하세요.

옵션
- `--role tank|dealer|bruiser|enchanter`: 역할을 직접 지정합니다. 기본값은 챔피언 분류로 자동 판단합니다.
  소나·소라카처럼 첫 분류가 서포터인 챔피언은 인챈터(회복·보호막·스킬 가속 중심)로 계산합니다.
- `--augment-levels 3,7,11,15`: 증강을 고르는 레벨. 이 레벨에 도달하면 알리고, 다음에 죽었을 때 증강 추천을 먼저 보여줍니다.
- `--no-history`: 게임 기록을 저장하지 않습니다. 기록은 `data/history/`에 게임마다 저장됩니다.
- `--damage ad|ap`: 피해 유형을 지정합니다. AP 말파이트처럼 일반적이지 않은 빌드일 때 씁니다.
- `--no-opgg`: OP.GG 데이터 없이 계산합니다.
- `--top N`: 추천 개수를 정합니다.

## 사용하는 데이터

| 데이터 | 출처 | 용도 |
|---|---|---|
| 10명의 챔피언, 레벨, 아이템, 사망 여부, 내 실제 스탯 | 게임 (Live Client Data API) | 현재 상황 |
| 아이템 스탯·가격, 챔피언 기본 스탯·스킬 설명 | Riot Data Dragon | 계산, 챔피언 성향 판단 |
| 증강 이름 | CommunityDragon (게임 파일에서 추출) | 증강 표시 |
| 칼바람 빌드·증강 통계 | OP.GG | 보정, 증강 추천 후보 (`--no-opgg`로 끌 수 있음) |

챔피언 성향(회복·보호막·고정 피해)은 Data Dragon의 스킬 설명에서 자동으로 판단합니다.
예를 들어 소라카·블라디미르는 회복 스킬 3개, 룰루·야스오는 보호막, 베인·피오라는 고정 피해로 분류됩니다.

## 동작 방식

| 단계 | 내용 | 데이터 |
|---|---|---|
| 1. 모델 | 탱커: 상대 피해 구성(물리/마법/고정)과 관통력을 반영한 **유효 체력 증가량 ÷ 가격**<br>딜러: 상대 5명의 방어력·마법 저항력·체력에 대해 **실제로 들어가는 피해 증가량 ÷ 가격**<br>브루저: 둘을 섞어서 계산 (아군에 탱커가 없으면 탱커 쪽 비중을 높임)<br>인챈터: 회복·보호막 효과 × 스킬 가속 × 주문력으로 본 **지원량 증가 ÷ 가격** (생존 30%)<br>주요 아이템 약 20개는 고유 효과를 같은 가치의 스탯으로 바꿔 더함 (예: 몰락한 왕의 검 = 공격력 +25, `stats.py`의 `UNIQUE_EFFECTS`) | Data Dragon |
| 2. 상황 보정 | 상대 회복 강함 → 치유 감소 (아군에 이미 있으면 낮게, 아군 점화만 있으면 중간)<br>상대 보호막 많음 → 보호막 파괴, 상대 치명타 많음 → 란두인<br>상대 전열 많음 → 체력 비례 피해, 신발은 상대 피해 구성으로 선택<br>상대 점화 2개 이상 → 회복 아이템 감점, 상대 회복·방어막 주문 → 상대 회복·보호막 점수에 반영<br>킬이 많거나 나를 자주 처치한 상대의 피해 구성을 더 무겁게 반영 | 아군·상대 아이템, 소환사 주문, KDA, 처치 기록 |
| 3. OP.GG 보정 | 칼바람 빌드의 픽률·승률로 가산점, 코어 빌드 표시<br>증강은 OP.GG 성능 점수에 역할·상대 구성에 따른 보정 | OP.GG MCP |
| 4. 지금 살 것 | 1순위 아이템의 재료 트리에서 보유 재료를 빼고, 보유 골드로 살 수 있는 큰 재료부터 추천 | 보유 골드 |
| 5. 교체 | 6칸이 가득 차면 보유 완성 아이템 하나를 팔고 추천 아이템을 넣었을 때 가장 이득인 조합을 추천<br>신발과 하위 아이템(재료)은 팔지 않고, 판매 금액을 더해 바로 완성할 수 있는 경우만 추천<br>보유 재료를 합쳐 팔지 않고도 완성할 수 있으면 교체 대신 그 아이템을 추천 | 판매 가격 |

### 증강 반영
게임 데이터에 증강 정보(`augment`가 들어간 필드)가 있으면 읽어서 반영합니다. Live Client Data API가 증강을 주는지는
아직 확인되지 않았습니다. 증강 정보가 없으면 상대·아군 증강은 빼고 아이템과 챔피언만으로 계산합니다.

증강 설명에서 효과를 분류합니다. 분류는 회복, 보호막, 치유 감소, 보호막 파괴, 탱커, 치명타, 고정 피해,
체력 비례 피해, 물리 딜, 마법 딜입니다.
- **상대 증강**: 팀 분석에 더해집니다. 예를 들어 상대 회복 증강이 많으면 치유 감소 아이템·증강의 점수가 오르고,
  고정 피해 증강은 상대 피해 구성에서 고정 피해 비중을 높입니다.
- **아군 증강**: 아군이 이미 치유 감소나 보호막 파괴를 가졌으면 중복 추천을 줄입니다.
- **내 증강**: 같은 방향의 아이템에 가산점을 줍니다(예: 치명타 증강 → 치명타 아이템). 다음 증강은 내 아이템·증강과의
  시너지로 추천하고, 이미 가진 증강은 빼고 추천합니다.

증강 이름은 CommunityDragon `cherry-augments.json`에서, 설명은 OP.GG 챔피언별 증강 목록에서 가져옵니다.
OP.GG 목록에 없는 증강은 CommunityDragon 아레나 데이터의 설명을 쓰거나, 설명 없이 이름만 표시합니다.

게임 중에는 내 실제 스탯(증강 효과 포함)을 Live Client Data API에서 받아서 씁니다.

칼바람은 죽었을 때나 게임 시작 직후 우물에서만 아이템을 살 수 있습니다. 그래서 `--watch` 모드는
내 챔피언이 죽는 순간(`isDead`가 거짓에서 참으로 바뀔 때)과 게임 시작 후 90초 안에만 추천을 출력합니다.
OP.GG 데이터는 감시를 시작할 때 미리 받아 두므로 죽었을 때 바로 결과가 나옵니다.
아이템·레벨이 바뀔 때마다 보고 싶으면 `--always`를 붙이세요.

아수라장 증강은 레벨 3, 7, 11, 15에 고르고, 첫 증강 외에는 죽어서 우물에 있을 때만 고를 수 있습니다.
그래서 증강 레벨에 도달하면 알리고, 다음에 죽었을 때 증강 추천을 아이템보다 먼저 보여줍니다.

### 증강 선택 화면 자동 읽기 (`--screen`)
죽어 있을 때와 게임 시작 직후에만 1~2초마다 주 모니터를 캡처해 Windows 기본 OCR(한국어)로 읽습니다.
화면 가운데에서 읽은 줄 중 증강 이름과 비슷한 것(유사도 75% 이상)을 찾아, 같은 높이에 나란히 있는 이름을 왼쪽부터 선택지로 봅니다.
카드 위치를 고정하지 않으므로 해상도가 달라도 맞출 필요가 없고, OCR이 한두 글자 틀려도 맞는 이름으로 고칩니다.
- 읽은 선택지는 터미널과 웹페이지 비교 칸에 자동으로 채워지고 등급·리롤 판단이 바로 나옵니다.
- 한 칸만 이름이 바뀌면 그 칸을 리롤한 것으로 보고 자동으로 "리롤함" 처리합니다.
- 게임 메모리를 읽거나 게임 화면에 그리지 않고 화면 캡처만 합니다(OBS·화면 공유와 같은 방식).
  Riot이 실시간 증강 추천 도구를 어디까지 허용하는지는 명확하지 않으니 개인 판단으로 사용하세요.
- 게임을 **전체 화면(독점)**으로 하면 캡처가 검게 나올 수 있습니다. **테두리 없는 창 모드**를 권장합니다.
- 게임이 주 모니터가 아니면 `--screen-monitor 1`처럼 모니터 번호를 지정합니다.
- 한국어 OCR이 없으면 설정 > 시간 및 언어 > 언어에서 한국어를 추가하세요.
- `--screen-image samples/image.png`로 전체 화면 스크린샷을 읽어 테스트할 수 있습니다 (읽는 영역: 화면 가로 18~86%, 세로 12~72%).

### 증강 등급 (S~D)
내 챔피언이 받을 수 있는 증강(OP.GG 목록) 전체를 지금 상황 점수로 줄 세워, 상위 10%는 S, 30%까지 A, 60%까지 B,
85%까지 C, 나머지는 D로 표시합니다. 상대 조합과 내 아이템이 반영되므로 같은 증강도 게임마다 등급이 달라질 수 있습니다.
OP.GG MCP 데이터의 `tier` 값(3~5)은 성능이 아니라 인기(표본 수)를 따라가서 등급으로 쓰지 않습니다.

웹페이지의 증강 비교 칸은 이름을 입력하는 즉시 등급을 보여줍니다. 카드를 리롤했으면 칸의 "리롤" 버튼을 누르고 새 이름을 입력합니다.

### 리롤 판단
증강 카드는 카드마다 한 번 리롤할 수 있고 같은 등급의 증강으로 바뀐다고 보고 계산합니다(위키 기준, 화면당 1번이라는 자료도 있음).
내 챔피언의 OP.GG 증강 중 같은 등급이면서 화면에 없는 것을 지금 상황 점수로 매겨, 리롤하면 그중 하나가 나온다고 봅니다.
- 1순위가 아닌 카드: 고르지 않을 카드라 리롤해도 손해가 없습니다. 1순위보다 좋은 증강이 나올 확률이 15% 이상이면 리롤을 추천합니다.
- 1순위 카드: 나머지 칸을 다 리롤한 뒤, "2순위와 새 카드 중 나은 쪽"의 기댓값이 1순위보다 높을 때만 리롤을 추천합니다.
- 리롤한 뒤에는 새 증강 이름으로 다시 비교하고, 리롤한 칸은 체크(명령에서는 이름 끝에 `*`)합니다.
- 웹페이지 주소에 `?c=둠&c=핀볼&c=남작의 도움`을 붙이면 입력칸을 채우고 바로 비교합니다.

### 게임 기록
`--watch` 모드는 게임마다 추천 내용, 보유 아이템, 승패(게임 종료 이벤트)를 `data/history/`에 저장합니다.
`history` 명령은 추천 1순위 아이템을 실제로 산 비율(추천 따름)과, 절반 이상 따른 게임과 아닌 게임의 승률을 보여줍니다.
판 수가 적으면 승률 차이는 우연일 수 있습니다.

## 한계

- 챔피언 스킬 계수는 계산하지 않습니다. 아이템 고유 효과는 주요 아이템만 스탯 근사값으로 반영하며, 값은 손으로 정한 것입니다.
- 인챈터 모델은 회복·보호막 효과, 스킬 가속, 주문력만 봅니다. 마나 회복, 이동 속도, 아군 강화 효과는 보정 점수로만 반영합니다.
- Live Client Data API의 처치 이벤트 이름(`KillerName`)이 태그 없는 소환사 이름이라고 가정합니다. 실제 게임에서 확인이 필요합니다.
- 증강 선택 화면의 선택지는 API로 읽을 수 없어서 화면 OCR(`--screen`)이나 직접 입력(웹페이지, `pick` 명령)으로 받습니다.
  OCR은 축소된 샘플 스크린샷 2장으로만 확인했고, 실제 게임 화면에서의 인식률은 아직 확인하지 못했습니다.
- OP.GG의 `aram` 데이터가 일반 칼바람인지 아수라장인지, 둘을 합친 것인지는 확인되지 않았습니다. 증강 데이터 목록을 보면 아수라장 데이터로 보입니다.
- OP.GG 증강의 `performance`와 `popular` 값은 정의가 공개되지 않았습니다. 인기 0인 증강은 표본이 적어 제외합니다.
- OP.GG MCP는 AI 에이전트용으로 공개된 비공식 인터페이스라 예고 없이 바뀔 수 있습니다. 공개 서비스에 쓰려면 이용약관을 확인하세요.

## WSL에서 실행할 때

롤은 Windows에서 실행되므로, WSL2 기본 설정(NAT)에서는 `127.0.0.1:2999`에 접속할 수 없습니다.
다음 방법 중 하나를 쓰세요.
- Windows용 Python으로 실행: `py -m aram_helper live --watch 2`
- WSL 미러 네트워킹 사용: `%UserProfile%\.wslconfig`에 아래 설정을 넣고 `wsl --shutdown`
  ```ini
  [wsl2]
  networkingMode=mirrored
  ```

## 파일 구성

- `aram_helper/ddragon.py`: Data Dragon 아이템·챔피언 데이터 (`data/`에 캐시)
- `aram_helper/stats.py`: 아이템 설명에서 스탯 읽기, 챔피언 최종 스탯 계산
- `aram_helper/opgg.py`: OP.GG MCP 호출과 응답 해석 (6시간 캐시)
- `aram_helper/augments.py`: 증강 이름·설명 데이터, 효과 분류 (`data/cdragon/`에 캐시)
- `aram_helper/analysis.py`: 팀 분석, 아이템·증강 추천
- `aram_helper/live.py`: 게임 중 Live Client Data API
- `aram_helper/notify.py`: 음성 안내, 추천 웹페이지
- `aram_helper/history.py`: 게임 기록 저장과 승률 요약 (`data/history/`)
- `aram_helper/screen.py`, `aram_helper/ocr.ps1`: 증강 선택 화면 캡처·OCR·이름 맞추기 (ocr.ps1은 UTF-8 BOM으로 저장해야 Windows PowerShell이 한글을 읽음)
- `aram_helper/cli.py`: 명령줄 실행
- `run.bat`: Windows 실행 메뉴, Python 자동 설치, 로그인 시 자동 실행 등록
